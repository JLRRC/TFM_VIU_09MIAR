### 1.bis Corrección de métrica `print()` (auditoría sobre la auditoría)

El audit v3 reportaba "7 prints en producción" y este informe inicialmente detectó "17". **Ambas cifras son falsos positivos parciales.** El grep capturaba:

| Origen | Cantidad | Naturaleza | Acción |
|---|:---:|---|---|
| `src/ur5_tools/install/_local_setup_util_*.py` | 8 | Artefactos de `colcon build` no trackeados (filesystem-only, ya en `.gitignore`) | Ignorar — no son código |

**Conclusión**: la regresión 7→17 era artificial. Tras instalar el test de gating `test_no_print_in_prod.py` (este sprint), la métrica cuenta sólo prints de código no-CLI no-build. Resultado: **0 prints en producción**.

### Patrones de comunicación (norte invariable)

| Caso | Mecanismo | Por qué |
|---|---|---|
| Pose objeto, fase actual, telemetría | **topic** | multi-suscriptor, no bloqueante |
| Plan/Exec MoveIt, attach, open/close | **action** (>500 ms) o **service** (<500 ms) | request/response tipado |
| Configuración runtime | **YAML + ROS 2 params** | recargable, auditable, **NO env vars** salvo `panel_env` |
| Constantes geométricas | **URDF/Xacro** + `kinematics.yaml` | fuente única MoveIt+Gazebo+RViz |
| World static | **SDF** + `world_tf_publisher` | puro Gazebo Sim moderno |
| Métricas históricas | **evidence_logger** (JSON/CSV) | trazabilidad académica |
| Arranque modular | **LifecycleNode** | configure/activate/deactivate explícito |
| Modos binarios | **launch arguments** | no mezclar con runtime |
