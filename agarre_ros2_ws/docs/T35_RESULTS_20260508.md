## ⚠️ T35 × 5 stress — flakiness observada (sesión post-3-verde)

Tras un stop+restart del stack y un nuevo cycle 1 stress (sesión
~20:00 UTC), TRANSPORT se atascó: el robot llegó a una pose
intermedia (object world ≈ -0.76, 0.36, 1.62) y no progresó más,
disparando FJT timeout 120s y fallback a MoveIt (que también colgó
por el bug feedback hang del path simple_controller_manager).

Diferencia clave vs el T35 × 3 verde:
- En T35 × 3 verde, el stack arrancó limpio una vez y los 3 cycles
  fueron consecutivos en la misma sesión sin reset.
- En T35 stress, hubo stop+restart del stack y luego cycle 1
  independiente. La pose inicial post-restart varía ligeramente y
  el seed IK genera trayectoria que no converge en 25s/120s.

**Hipótesis** (no confirmada en esta sesión por tiempo):
- El IK de MoveIt es no-determinista entre arranques (depende de la
  pose inicial exacta del joint_state al momento del compute_ik).
- Para algunos seeds, la trayectoria multi-waypoint generada cruza
  un punto donde el path tolerance del controller se viola y el
  goal se aborta sin "Goal reached, success!".

**Mitigaciones futuras** (si se quiere estabilizar T35 × 5):
- H14: aumentar `path_tolerance` del controller para TRANSPORT (parámetro
  `controller_path_tolerance_rad` en moveit_bridge config).
- H15: pre-validar el IK calculado con un check `is_reachable` (joint
  limits + workspace radius) y si no, retry con seed alternativo.
- H16: usar `/move_group/compute_cartesian_path` con avoid_collisions
  para TRANSPORT en lugar de IK + 2-points (más robusto pero más lento).

## Reproducir el T35 × 3 verde

```bash
git checkout T35-3-cycles-verde-20260508
cd agarre_ros2_ws
colcon build --packages-select ur5_tools ur5_bringup --symlink-install
source install/setup.bash

# Arrancar stack UNA vez
rm -f log/ros2_launch.log
PANEL_COLD_BOOT=1 PANEL_FORCE_OFFSCREEN=1 PANEL_START_STACK=1 \
PANEL_LAUNCH_MOVEIT=1 MOVEIT_MODE=move_group PANEL_AUTO_BRIDGE=0 \
PANEL_AUTO_RELEASE_DROP_OBJECTS=1 PANEL_PICK_DEMO_USE_ORCHESTRATOR=1 \
./scripts/start_panel_v2.sh --bg

# Esperar ready
until grep -q "STATE READY" log/ros2_launch.log; do sleep 5; done

# 3 cycles consecutivos
for i in 1 2 3; do
  echo "=== Cycle $i ==="
  ros2 action send_goal /pick_place ur5_panel_interfaces/action/PickPlace \
    "{object_name: 'pick_demo', drop_xyz_world: {x: -1.30, y: 0.0, z: 1.10}, object_pose_world_hint: {position: {x: 0.0, y: 0.0, z: 0.0}, orientation: {x: 0.0, y: 0.0, z: 0.0, w: 1.0}}}"
done
```
