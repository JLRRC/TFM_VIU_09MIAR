### Patrones de comunicación recomendados

| Caso | Mecanismo | Justificación |
|------|-----------|---------------|
| Pose objeto, estado fase, telemetría | **topic** | Multi-suscriptor, no bloqueante, baratos |
| Plan/exec MoveIt, attach/detach, open/close | **action** (largo) o **service** (corto) | Necesitan request/response; action si lleva > 500 ms |

| Constantes geométricas robot | **URDF/Xacro** + `kinematics.yaml` | Fuente única, MoveIt + Gazebo + RViz coherentes |
| World static / objetos pickeables | **SDF** + `world_tf_publisher` | Puro Gazebo Sim moderno |
| Métricas históricas | **evidence_logger** (JSON/CSV) | Trazabilidad académica |
| Switching arranque/parada modular | **LifecycleNode** | Estados configure/activate/deactivate |
| Variables binarias de modo | **launch arguments** | No mezclar con runtime |
| Variables de desarrollo / debug | **os.environ.get** (sólo en `*_params.py`) | Minimizar; idealmente eliminar |
