# auditoria

Directorio de auditoria operativa del workspace.

## Contenido

- `panel_audit/`: artefactos y logs de ejecucion del panel (infer, execute, reset, visualize, etc.).
- `workspace/`: auditorias de estructura, limpieza y mantenimiento del repositorio.
- `tmp/`: temporales de regeneracion no versionados para procesos reproducibles.

## Uso

Este directorio conserva evidencia tecnica de operacion y mantenimiento.
No sustituye los artefactos finales del documento, que permanecen en `../reports/`.
